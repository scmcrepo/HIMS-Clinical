## Implementation notes

- Token: 32 bytes from SecureRandom, base64url, prefixed hms_agt_ so it is greppable in leak scans. Store SHA-256 of the token only. Plaintext is returned once at creation and never again — no recovery path, only reissue.
- Default expiry 90 days per the confirmed decision. Overlapping rotation means a tenant may hold two valid tokens simultaneously; do not enforce a single active token.
- branch_id nullable — a token may be tenant-wide or pinned to one branch, per the confirmed decision.
- Scopes are feature keys. Validate at issue time that every requested scope is one of the five agent feature keys; reject unknown scopes rather than storing them.
- Controller is @PreAuthorize(hasPermission('AGENT_TOKEN_MANAGE','')) — HOSPITAL_ADMIN only.
- The entity is tenant-scoped: it must carry tenant_id and be covered by the Hibernate tenantFilter like every other tenant table.

## Definition of done

Card-specific:
- [ ] Issuing returns the plaintext token exactly once; a subsequent GET never returns it.
- [ ] Only the SHA-256 hash is persisted — test asserts the plaintext string appears nowhere in the row.
- [ ] Revocation is immediate: revoked_at set, token rejected thereafter (verified in T-005).
- [ ] Tenant B cannot list, revoke or use tenant A's tokens — Testcontainers test asserting absence.
- [ ] A non-HOSPITAL_ADMIN tenant user receives 403. Test uses a tenant-scoped user, not SUPERADMIN.
- [ ] Unknown or non-agent scopes are rejected at issue time.
- [ ] Audit: issuance and revocation emit agent.token.issued / agent.token.revoked log events.
