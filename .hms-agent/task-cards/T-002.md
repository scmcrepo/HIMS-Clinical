## Implementation notes

- Add micrometer-registry-prometheus; spring-boot-starter-actuator is already a dependency. Expose health, info, prometheus only.
- CorrelationIdFilter reads X-Correlation-Id or generates one, puts correlationId into MDC, echoes it on the response, clears in finally. Tenant and branch go into MDC from TenantResolutionFilter, which already has them — extend that filter rather than duplicating resolution.
- MDC is a ThreadLocal, so it does not survive @Async. Wire an MdcTaskDecorator into the existing asyncExecutor in AsyncConfig, mirroring the tenant-context pattern in BulkImportAsyncService.
- Add Prometheus to docker-compose.logging.yml alongside Loki/Promtail/Grafana, and provision it as a second Grafana datasource as code. Tempo is deferred to WO-004 per the confirmed decision.
- Global metric tags: application, env. Do NOT tag by anything patient-scoped.
