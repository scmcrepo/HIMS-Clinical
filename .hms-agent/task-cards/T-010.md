## Implementation notes

- Follow the existing feature-module conventions: TanStack Query for server state, Zod + React Hook Form for the issue form, Radix Dialog, Tailwind. Mirror an existing settings module rather than inventing a layout.
- The plaintext token is shown exactly once, in a modal, with a copy button and an explicit warning that it cannot be retrieved again. This is the whole reason the UI exists — get the copy interaction right.
- Revocation needs a confirmation step; revoking a live agent credential takes the hospital's automation offline immediately.
- Show last_used_at and expiry prominently — a token unused for 90 days is a token to revoke.
- Do NOT add this path to sonar.coverage.exclusions. Several frontend feature modules are excluded there; new agent-facing UI should be covered.
