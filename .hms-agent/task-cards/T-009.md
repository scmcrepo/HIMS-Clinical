## Goal

GET /tools/schema returns JSON Schema for all four tools, generated from the live OpenAPI document so the Python side cannot drift from the Java contract.

## Implementation notes

- Generate from the springdoc OpenAPI document at runtime rather than hand-maintaining schemas. Two hand-written copies of a schema always diverge, and the first symptom is an agent confidently passing a parameter that no longer exists.
- Output shape should be directly consumable as LangChain/LangGraph tool definitions: name, description, parameters as JSON Schema. Keep descriptions meaningful — they are what the model reads to decide which tool to call.
- Scope AGENT_TOOLS_READ.
