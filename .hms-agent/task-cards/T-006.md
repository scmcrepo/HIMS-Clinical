## Implementation notes

- Ship one real tool in this card rather than a bare skeleton — a skeleton with no tool cannot be verified end to end. check_bed_occupancy is the right choice: read-only, no PII in the response, delegates to the existing BedManagementService.
- Error envelope: data carries code (stable enum), retryable (boolean), correlationId. A bare 500 teaches an LLM nothing except to loop or give up. Map BusinessRuleViolationException to specific codes rather than a generic failure.
- AgentToolAuditService writes exactly one agent_tool_invocations row per call, on success AND failure. Surrogate ids only — no patient names, no free text.
- Metrics: hms_agent_tool_invocations_total{tool,outcome} and hms_agent_tool_duration_seconds{tool}. Assert them in a test with SimpleMeterRegistry — a Counter field that is never incremented compiles perfectly.
- Delegate to existing services. Do not reimplement bed logic in the agent layer.
